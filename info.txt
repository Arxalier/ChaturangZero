Piece Definitions & Encodings (

pieces.py
):
Numbered integer representations: EMPTY=0, PAWN=1, HORSE=2, ELEPHANT=3, CHARIOT=4, MINISTER=5, KING=6.
Sign determines color: Positive for White (+1), Negative for Black (-1).
Traditional Sanskrit aliases provided: Padāti (Pawn), Ashwa (Horse), Gaja/Hasti (Elephant), Ratha (Chariot), Mantri (Minister), Rāja (King).
Board State & Transitions (

board.py
):
create_starting_board(): Sets up the initial $8 \times 8$ board with Murray/Golombek symmetry (Kings face each other on column 4/e-file; Ministers face each other on column 3/d-file).
make_move(): Applies a move and returns a new copy of the board (preserving immutability for MCTS tree search).
Automatic Promotion: Pawns automatically promote strictly to Ministers (Mantri) upon reaching the opponent's back rank (row 0 for White, row 7 for Black).
Move Generators (

moves.py
):
Pseudo-legal move generators for each piece type:
Chariot (Ratha): Orthogonal sliding ray (like a modern Rook).
Horse (Ashwa): Standard L-shaped leap (jumps over intervening pieces).
Elephant (Gaja): Strict 2-square diagonal leap (jumps over intervening squares).
Minister (Mantri): 1-square diagonal step in any of the 4 directions.
King (Rāja): 1-square step in any 8 directions (no castling).
Foot Soldier (Padāti): 1-square straight forward, 1-square diagonal forward capture (no initial double step, no en passant).
Rules & Outcome Logic (

rules.py
):
is_in_check(): King attack detection.
get_all_legal_moves(): Prunes pseudo-legal moves that leave or put own King in check.
get_game_outcome(): Evaluates terminal game states per Murray/Golombek rules:
Checkmate (+1 win / -1 loss): In check with 0 legal moves.
Bare King (+1 win / -1 loss): If a player captures the opponent's second-to-last piece (leaving the enemy King isolated on the board), the baring player instantly wins.
Stalemate (+1 win): If not in check but has 0 legal moves, the stalemated player wins (+1) (not a draw!).
perft(): Performance and correctness move-tree enumeration function.

env.py

Part 2: How the Board is Stored as a 3D Matrix
There are two layers to understand: how it is stored right now in Python, and how it is designed to be stored as a 3D tensor for the Neural Network.

1. In the Current Python Engine: 2D Matrix
In 

chaturanga/board.py
, the active game engine stores the board as a single $8 \times 8$ 2D NumPy array of np.int8:

python
board = np.zeros((8, 8), dtype=np.int8)
Each cell $(r, c)$ contains an integer:

0: Empty
+1 to +6: White pieces (Pawn, Horse, Elephant, Chariot, Minister, King)
-1 to -6: Black pieces (-Pawn, -Horse, -Elephant, -Chariot, -Minister, -King)
2. For the Neural Network (AlphaZero): 13-Channel 3D Tensor
A single 2D integer array is unsuitable for Convolutional Neural Networks (CNNs/ResNets) because integer values imply an artificial ordinal scale (e.g., King 6 would numerically appear "six times larger" than Pawn 1).

As specified in 

projectDetails.txt
 and planned for Phase 2, the board state is converted into a binary 3D tensor of shape $(13, 8, 8)$ (or $(8, 8, 13)$ depending on PyTorch channels_first convention):

$$\text{Shape: } (C, H, W) = (13, 8, 8)$$

The 13 binary $(8 \times 8)$ channels (planes) represent:

Channel Index	Contents	Description
0	White Pawn (Padāti)	1 if White Pawn at $(r, c)$, else 0
1	White Horse (Ashwa)	1 if White Horse at $(r, c)$, else 0
2	White Elephant (Gaja)	1 if White Elephant at $(r, c)$, else 0
3	White Chariot (Ratha)	1 if White Chariot at $(r, c)$, else 0
4	White Minister (Mantri)	1 if White Minister at $(r, c)$, else 0
5	White King (Rāja)	1 if White King at $(r, c)$, else 0
6	Black Pawn	1 if Black Pawn at $(r, c)$, else 0
7	Black Horse	1 if Black Horse at $(r, c)$, else 0
8	Black Elephant	1 if Black Elephant at $(r, c)$, else 0
9	Black Chariot	1 if Black Chariot at $(r, c)$, else 0
10	Black Minister	1 if Black Minister at $(r, c)$, else 0
11	Black King	1 if Black King at $(r, c)$, else 0
12	Turn Indicator	All 1s if White to move; all 0s if Black to move
How the Conversion Function Works
When you implement the Phase 2 tensor conversion function (e.g., board_to_tensor(board, current_player)), it operates like this:

python
import numpy as np
def board_to_tensor(board: np.ndarray, current_player: int) -> np.ndarray:
    """
    Converts 8x8 integer board into a 13x8x8 binary feature tensor.
    """
    tensor = np.zeros((13, 8, 8), dtype=np.float32)
    # Channels 0-5: White pieces (+1 to +6)
    for piece_type in range(1, 7):
        tensor[piece_type - 1] = (board == piece_type).astype(np.float32)
    # Channels 6-11: Black pieces (-1 to -6)
    for piece_type in range(1, 7):
        tensor[5 + piece_type] = (board == -piece_type).astype(np.float32)
    # Channel 12: Current player turn indicator
    if current_player == 1:  # White's turn
        tensor[12].fill(1.0)
    else:                    # Black's turn
        tensor[12].fill(0.0)
    return tensor
This 3D matrix is then fed directly into the ResNet convolutional layers during self-play and MCTS evaluations.
